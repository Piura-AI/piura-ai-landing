# Kit de marca de Piura AI

Logos, colores y guía de uso de la comunidad. Empieza por **`Guia-de-marca-Piura-AI.pdf`**: en 9 páginas explica qué versión usar y cómo.

## Qué hay

| Carpeta            | Contenido                                                        |
| ------------------ | ---------------------------------------------------------------- |
| `logo-horizontal/` | Zorro + “Piura AI” en una línea. Es la versión principal.        |
| `logo-cuadrado/`   | Zorro arriba y “Piura AI” abajo, en lienzo cuadrado.             |
| `icono/`           | Solo el zorro.                                                   |
| `redes/`           | Avatares de 1000×1000 (claro y oscuro), aptos para recorte circular. |
| `colores/`         | Paleta en `colores.css` y `colores.json`.                        |

Cada carpeta de logo trae tres subcarpetas:

- `svg/`: vectorial. Úsalo siempre que puedas (diseño, imprenta, web).
- `png-transparente/`: sin fondo, para ponerlo sobre tu propio fondo.
- `png-con-fondo/`: con el color de fondo recomendado, listo para pegar.

## Versiones

| Nombre en el archivo  | Cuándo usarla                                          |
| --------------------- | ------------------------------------------------------ |
| `color-fondo-claro`   | Por defecto. Sobre crema, blanco o fondos claros.      |
| `color-fondo-oscuro`  | Sobre azul marino, negro o fondos oscuros.             |
| `una-tinta-azul`      | Impresión a un color, sellos y grabados.               |
| `una-tinta-blanco`    | Sobre fotos oscuras o colores intensos.                |

## Colores principales

| Color       | HEX       |
| ----------- | --------- |
| Terracota   | `#A8502A` |
| Azul marino | `#22384A` |
| Crema       | `#F6F3EC` |

## Tipografías

- **Space Grotesk** (titulares): https://fonts.google.com/specimen/Space+Grotesk
- **IBM Plex Sans** (cuerpo): https://fonts.google.com/specimen/IBM+Plex+Sans

Ambas son gratuitas y también están en Canva y Google Slides.

## Reglas rápidas

- El nombre se escribe “Piura AI”: con espacio y “AI” en mayúsculas.
- No estires, gires ni recolorees el logo, y no le agregues sombras.
- Deja aire alrededor del logo y cuida el contraste con el fondo.

Dudas o piezas nuevas: contacto@piura-ai.org
